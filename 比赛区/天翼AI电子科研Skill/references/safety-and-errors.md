# 真实设备安全、错误与恢复

读取时机：连接真实仪器、准备写设置、出现失败或需要判断是否重试时读本页。只做离线分析时
可以跳过。

## 默认只读

- `inspect`、`measure`、`fetch`、`analyze`、`advise` 不改变设备状态。
- 不发送 `*RST`，不自动打开输出，不自动改量程、耦合、触发或时基。
- 唯一的设备写入入口是 `autoscale --apply`；没有显式 `--apply` 时只给建议。
- 即使使用 `--apply`，也要先让用户确认设备地址、通道、接线、输入阻抗、量程和电压/电流上限。
  不能把“用户让我测一下”解释成“允许我改设备设置”。

`autoscale --apply` 的写入必须经过“执行 → 回读 → 比对”验证。写入被接受但回读不匹配时，
记录 `verification_failed`，不要把“命令没报错”当成“设置已生效”。

## 连接真实设备前

确认以下内容，缺一项就保持只读：

1. 地址和端口来自 `discover`、用户提供或已知资产，不猜网段和 IP。
2. 探头/接线、通道、输入阻抗和量程与待测信号匹配。
3. 待测电压/电流不超过探头和仪器上限；需要衰减或隔离时先处理。
4. 写入范围已由用户明确授权；需要恢复时知道原设置或已保存快照。
5. 设备错误队列在操作前后都可读；读不到时把 `error_queue_unavailable` 当成未验证，而不是成功。

## SCPI 会话语义

- 一次查询使用一个总截止时间；文本和二进制块共享接收缓冲。
- 响应可以分段到达；CRLF 和块尾终止符都可能跨包。
- 超时或不完整响应会使会话失效并关闭。再次通信必须新建会话，不能把迟到响应当成下一条命令的结果。
- 不自动重放写入或查询。失败后先只读诊断，不要盲目重试同一条写命令。
- 设备拒绝命令、回读不匹配、空响应、解析失败要分开归类；不要统一写成“解析失败”。

## 错误类别

`failures[].category` 和 `errors` 中的类别：

| 类别 | 含义 | 首要动作 |
| --- | --- | --- |
| `unsupported` | 设备错误队列拒绝了该命令或该功能 | 换方言或改用只读替代；不要假设设备支持 |
| `verification_failed` | 写入被接受，但回读值与请求值不匹配 | 保留 `write_results` 和错误队列；人工决定恢复 |
| `no_response` | 响应为空，且错误队列没有给出原因 | 检查通道/触发/传输格式；不要伪造 0 值 |
| `parse_error` | 响应非数值、块头非法或协议帧无法解析 | 检查格式、字节序、manifest 和采样率 |
| `configuration_error` | 本地参数、网段、通道、协议声明或采样率非法 | 修正参数后再调用；不要重试原参数 |
| `transport_error` | 连接、套接字或底层传输失败 | 检查网络/端口/桥接；保持只读 |
| `timeout` | 超过查询或连接截止时间 | 关闭旧会话；确认设备状态后新建会话 |
| `error_queue_unavailable` | 读取 `SYST:ERR?` 本身失败 | 把本次结果标为未验证；不要声称成功 |
| `internal_error` | 未归类的内部异常 | 保存完整 JSON，报告为未验证 |

`failures` 条目通常含 `category`、`command`、`message`；测量还可能带 `metric`，autoscale
写入验证可能带 `verification_error`。`device_errors` 是设备错误队列的原始文本，不等于
Agent 侧失败列表。

## autoscale 部分成功

- `applied=true` 表示所有计划设置都经过回读验证；关闭连接失败不会把它改成部分成功，但退出码仍为 `2`。
- `partially_applied=true` 表示只有一部分设置验证成功，退出码为 `3`。
- 出现部分成功时，先读 `write_results`、`failures` 和 `device_errors`，确认哪些设置已经改变；
  不要自动重发全部设置。需要恢复时按用户确认的原设置人工处理，并记录未覆盖项。
- 没有验证任何设置时退出码为 `2`；只读建议本身完成时为 `0`。

## 证据与报告

每次真实设备操作至少保留：

- 完整 JSON（设备地址、通道、时间戳、命令、指标、`failures`、`device_errors`）；
- 使用的采样率、单位、量程和数据来源；
- 未执行项、未验证项和需要人工恢复的设置。

报告里区分“测量成功”“写入已验证”“只读诊断”“未验证”。测试通过不等于实机验收，
离线演示也不等于设备已经连接。
